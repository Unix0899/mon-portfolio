# Harry Mulembwe — Portfolio

Personal portfolio of Harry Mulembwe, Data & Business Analyst based in Brussels.
Available in English, French and Dutch.

## Structure

```text
index.html                    Home page
styles.css                    Home page styles
projects/cryptobel/           Cryptobel case study
projects/lexlau/              LexLau / Klavis.app case study (synthetic reconstruction)
projects/odres/               ODRES Group case study (synthetic reconstruction)
assets/cv/                    Public CVs (EN, FR)
assets/i18n.js                Language switcher (EN / FR / NL)
assets/i18n/home.js           FR + NL translations of the home page
assets/i18n/cryptobel.js      FR + NL translations of the Cryptobel case study
assets/i18n/lexlau.js         FR + NL translations of the LexLau case study
assets/i18n/odres.js          FR + NL translations of the ODRES case study
assets/site.js                Scroll reveal, active nav link, reading progress
assets/common.css             Styles shared by every page
vercel.json                   Vercel settings (clean URLs with trailing slash)
```

Static HTML/CSS/JS, no build step.

## Translations

English text lives directly in the HTML. Every translatable element has a
`data-i18n="key"` attribute; the French and Dutch versions of that key are in
`assets/i18n/<page>.js`. To change a sentence, edit it in the HTML (English) and
in the matching key of the translation file (FR + NL).

A language can be forced with a URL parameter, e.g. `/?lang=nl` or
`/projects/cryptobel/?lang=fr`. The visitor's choice is remembered across pages.

## Run locally

```bash
python -m http.server 3000
```

Then open http://localhost:3000.

## Deploy

Pushing to the `main` branch on GitHub triggers a new Vercel deployment.

## LexLau / Klavis.app (synthetic reconstruction)

`projects/lexlau/proof/` holds the 8 proofs generated by the public repository
`lexlau-klavis-ai-workflow-demo` (`scripts/make_proofs.py`: screenshots of the running demo, SQL and

database, tests and SQL views. Synthetic demonstration data: no real client, legal-case or
confidential LexLau/Klavis data. Never present the project as "I built Klavis".
